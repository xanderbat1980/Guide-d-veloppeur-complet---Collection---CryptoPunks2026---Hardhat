# Guide-d-veloppeur-complet---Collection---CryptoPunks2026---Hardhat
Ce guide présente une implémentation développeur complète d’une collection originale de type CryptoPunks avec Hardhat, en s’appuyant sur le standard ERC-721, les scripts de déploiement Hardhat, l’intégration hardhat-ethers, et une architecture metadata compatible avec l’écosystème Ethereum moderne.
